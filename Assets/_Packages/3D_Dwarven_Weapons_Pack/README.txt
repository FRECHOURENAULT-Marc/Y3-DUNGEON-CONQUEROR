3D Dwarven Weapons Pack
Generated with polyy.ai

24 dwarven weapons in GLB format. Full-detail meshes straight from the generator.

Contents
  models/    GLB meshes, one file per weapon
  previews/  animated turntable GIF for each weapon, same filename
  LICENSE.txt

Engine notes
  Godot 4:   drag the .glb into the FileSystem dock and instance the scene.
  Unity:     GLB needs glTFast or UnityGLTF; both read these files directly.
  Unreal 5:  Import the .glb through the Content Browser.
  Blender:   File > Import > glTF 2.0.

Mesh details
  One mesh and one PBR material per file, with base color and
  metallic/roughness textures embedded (PNG). No normal maps.
  Roughly 50,528 to 54,999 triangles per model.
  Y-up. The origin sits at the center of the bounding box, and each
  model is normalized to fit a box about 1 unit across, so a dagger and
  a polearm come at the same size; set the scale per weapon in the engine.
